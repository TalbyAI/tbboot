---
name: issue-flow
description: Implement or review one prepared GitHub Issue inside the assigned worktree. Use for the Issue 74 local workflow.
---

Read `AGENTS.md`, `CONTEXT.md`, and the Issue context before acting. Respect
the Issue's acceptance criteria and keep every change in the assigned
worktree. Use the repository's existing commands and tests. Do not publish,
approve, merge, close, or delete work unless the host explicitly authorizes
that operation.
